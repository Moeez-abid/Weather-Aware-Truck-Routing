# Weather-Aware Truck Routing

A React + Django web app that helps a truck driver choose the safest route based on weather, load weight and travel time.

The app generates three route options, checks the forecast at the truck's estimated arrival time at each checkpoint, classifies weather risk, and recommends the best route. A weather heatmap with a 0–48 hour forecast slider covers the trip corridor.

This project is under active development. See [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md) for the design and build order.
